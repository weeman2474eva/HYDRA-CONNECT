# HYDRA CONNECT

Android customer companion app for the HYDRA CONNECT reseller panel.

Default API:
`https://h1kb5tr.ezp1.eu/connect/api/`

## Build APK with GitHub Actions

1. Open **Actions** in this repository.
2. Open **Build HYDRA CONNECT APK**.
3. Run the workflow, or push a change to `main`.
4. When the run finishes, download the **HYDRA-CONNECT-APK** artifact.

The generated file is `HYDRA-CONNECT.apk`.
